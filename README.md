# Autolupa

A price comparison site for used cars in Czechia and Slovakia, in the spirit of Heureka.cz.

Autolupa gathers used-car listings from Czech and Slovak marketplaces and dealer feeds. It reads each ad to work out the make, model, year, mileage, fuel and condition, and labels damaged, non-running and parts-only cars clearly. Every car is compared with similar ones so buyers can see at a glance whether the price is fair, and one click takes them to the original listing.

The site is available in Czech and Slovak. Signed-in users can bookmark cars, compare them side by side and save searches.
